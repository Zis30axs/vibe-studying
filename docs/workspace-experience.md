# 主界面体验更新

基于已发布的 v0.5.0，保留数学钉板、各学科工作台、Agent、教材、历史和模型设置。不混入未发布的 v0.6.0 Skill / Embedding 开发包。

## 使用

顶部“查找题目与工具”或 Ctrl/Cmd+K 打开快速查找：按题目名称、题号、学科与标签搜索，并跳转各工作台。方向键选择、Enter 打开、Esc 关闭。已有模态弹窗或正在提交时不会叠开导航。切换设置页仍经过未保存配置的离开确认。搜索仅使用学生侧字段，不搜索答案、评分项、解析；不提交作答也不调用模型。

作答区上方显示当前题、练习阶段和上一题/下一题。题目顺序跟随当前学科与搜索范围，首尾禁用；无自动提交。目录“草稿”和“已提交”只描述记录状态，不表示掌握或正式判分。

“专注作答”收起侧栏；“退出专注”恢复进入前栏宽和展开状态。刷新后退出专注使用默认布局。调整布局不重建答题框和数学工具；现有草稿保存流程不变。

自动记住最后浏览的题号，下次打开时定位到仍存在的该题；缺失则回退第一题。可选缓存 `examcraft.workspace-ui.v1` 仅包含 version、lastQuestionId 和 motion，没有题干、答案、密钥、教材或学习历史，不修改旧学习记录。

## 动效

主作答卡、导航选中态、目录与分组按钮使用现有主题色。选项卡和底部操作条在答题面板滚动时保持可达。快速查找、题面切换、审阅反馈、抽屉、按钮反馈与初始加载有短动画；输入和拖动栏宽不触发整页动画。

快速查找“减少界面动画”可关闭动效，“恢复界面动画”恢复跟随系统。系统 prefers-reduced-motion: reduce 始终优先。浅色、深色、本地壁纸沿用原设置；不修改图形和教材像素，窄窗口保留抽屉。

## 验证

`npm run check`、`npm run test:browser`、`npm run test:e2e`。测试覆盖缓存白名单、空草稿标记、参考答案不泄露、搜索边界、模态焦点、分页、恢复、专注不重建编辑器、减少动画、加载与各宽度。以对应提交实际 CI 结果为准；不访问个人学习记录。
