# 数学挑战 · 综合试卷

左侧导航的“数学挑战”是独立模式，也可通过 Ctrl / Cmd + K 搜索进入。当前提供“空间向量、直线与圆”原创综合卷，衔接二次函数、三角与不等式知识；范围按当前学习进度设计，试卷版式借鉴高考，不是历年真题或覆盖高中全部内容的高考卷。

## 版式

| 题型            | 题数 | 每题分值               | 合计 |
| --------------- | ---- | ---------------------- | ---- |
| 单项选择        | 8    | 5                      | 40   |
| 多项选择        | 3    | 6                      | 18   |
| 填空            | 3    | 5                      | 15   |
| 解答（19 题版） | 5    | 13、15、15、17、17     | 77   |
| 解答（20 题版） | 6    | 12、12、12、13、13、15 | 77   |

两种版式均为 150 分、120 分钟。20 题版是本应用的扩展练习版式，解答题分值为本挑战自设。两版共享部分基础题，重做同一套试卷不是随机生成一套新试卷。

## 作答与交卷

选择试卷并开始后，答题卡可跳转任意题目、标记待检查题；多选题使用复选框，填空、解答题使用文字输入，草稿纸随该次试卷保存。只有交卷后才提供参考答案、解析和自评步骤。交卷前会提示空题数量，可返回继续作答。

作答、当前题目、标记和草稿自动保存到本机。离开挑战页面会立即提交待保存改动，切换页面或关闭应用不暂停考试；重开后从原截止时间继续计时。到时自动收卷，以最后成功保存的答案为准，截止后的输入不会写入该次答卷。遇到保存失败，先保留当前页面并重试保存。

每次重做保留独立记录。同一时间只允许一份进行中的试卷，先继续或交卷再开始下一份；挑战历史可单独打开查看。

## 核分

单选自动核分。多选采用明确的本地练习规则：全对 6 分，漏选且没有错选得 3 分，错选或未选得 0 分；并不声称适用于所有年份、地区的实际高考细则。

填空、解答题的非空答案在交卷后标为“待自评”，对照答案与步骤输入自己的得分；空白题默认记 0 分；如在纸上完成，可按实际作答更正自评分。客观题得分单列，所有主观题核完后才显示总分。该总分含自行评定的分数，是练习自评成绩。

## 存储与实现

主进程在独立的 `math-challenges.json` 中保存挑战，使用已有原子写入队列；不会把整卷拆成普通题库提交，也不会改写已有 `study-state.json` 或题库。一次考试固定保存当时的完整试卷快照，之后题目内容更新不会改变历史答案或评分依据。

渲染进程在交卷前仅收到题面、选项与答卷，参考答案、解析、正确选项和评分步骤留在主进程。出题数据由内置原创内容提供，不需要模型 API 或联网；当前不支持把普通题库自动拼成多选完整试卷。
