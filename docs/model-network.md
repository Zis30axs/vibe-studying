# 模型连接与 Clash Verge

在「模型设置」为当前配置选择网络连接方式，再保存：

- **直连**：使用普通 Node HTTP(S) 请求和默认 DNS，不自动采用系统代理；Clash TUN 可接管这条路线。
- **系统代理**：读取系统为本次目标选择的路线。支持本机回环 HTTP 代理；系统明确返回直连时，使用上述直连方式。
- **本机代理**：填写 Clash 显示的 HTTP 或混合代理端口，例如 `http://127.0.0.1:7890`。端口只是示例，请使用自己已配置的端口。支持 `[::1]`，不接受远程地址、SOCKS、认证信息或额外路径。

获取模型、测试 API、实际模型生成和 Agent 工具请求共用这项选择。获取模型和测试 API 会使用编辑器当前值；实际生成使用已保存值。切换网络时会取消旧请求。旧配置默认直连，不会未经选择改变请求路线。

模型基础地址支持 HTTP/HTTPS、localhost、私网、IP、自定义端口和普通路径。不接受 URL 内嵌账号密码、查询参数或片段；密钥通过鉴权头发送，应用在基础地址后追加协议操作路径。模型连接不再预先解析 DNS 或按公网、私网、Fake-IP 分类拦截。

模型 ID 可含中文、空格和普通符号，去掉首尾空格后为 1–120 个字符，不接受控制字符。

本机代理模式为 HTTPS 目标通过 HTTP CONNECT 建立到原始主机和实际端口的隧道，保留正常 TLS 证书校验；HTTP 目标通过代理发送完整目标 URL。代理负责上游解析和路由。应用不会修改 Clash、操作系统代理、证书或防火墙设置。

代理不可用、要求认证或返回错误时会明确失败，不自动改走直连，也不自动重试。服务返回重定向时仍不跟随，请改填最终 API 基础地址。超时或取消会终止当前连接。系统模式若无法获得受支持的路线，可明确选择本机代理并填写已有 HTTP/混合端口。

本地回归使用合成凭据、仅用于测试的证书与回环代理。它验证请求方式、证书校验和取消行为，不代表用户的真实 API、Clash 实例、套餐额度或模型生成质量已验证。

实现依据：[Electron 代理模式](https://www.electronjs.org/docs/latest/api/structures/proxy-config)、[Node HTTPS](https://nodejs.org/api/https.html)、[Node TLS](https://nodejs.org/api/tls.html)。
