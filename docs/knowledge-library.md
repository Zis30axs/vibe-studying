# 六科教材：本机 PDF 知识库

本功能提供用户自己选择的 PDF 的本地导入、阅读和检索。**没有预装或下载任何教材**。支持语文、数学、英语、政治、历史和地理，各书有可编辑的学科、名称和版本。未确认的册次显示“版本待确认”；政治预设“必修四《哲学与文化》1–5 课”只是范围提示，不推定目录或页码。章节名和起止页由用户填写。旧版政治资料缺少学科字段时按政治兼容读取。

## 阅读与检索

- 通过系统文件选择器导入；前端不能指定任意文件路径。文件保存在本机应用数据目录，以内容摘要标识，重复文件去重。
- 引文页码统一为 **PDF 物理页，从 1 开始**，包括封面和目录；不推测书上印刷页码。
- 搜索限定到用户选中的一本书，并可进一步选择章节或物理页码范围。中文使用本地词法匹配；不是语义搜索，不建立云端向量库。
- PDF.js 解析和固定画布渲染，不使用 PDF 浏览器插件、网页嵌入或可点击外链层。脚本、表单/XFA、注释交互与外部文档 URL 不执行。
- 无可提取文字的页会提示限制。扫描 PDF 需要先做 OCR，本版不内置 OCR；图片中的文字、复杂公式、表格顺序、地图含义不能靠当前文本提取可靠识别。为限制运行时资源，本版关闭 WASM 图像编解码扩展，少见图像编码可能无法显示；遇到缺图需用原 PDF 软件核对并重新导出兼容副本。
- 导入、检索与阅读不调用模型。错误不会输出原始 PDF 内容或本机路径；导入可取消，解析在独立线程中设有时限。

## 按需提供给 Advisor

1. 在检索结果中明确选择少量片段。
2. 在当前学科题目的 Ask Advisor 面板查看书名、物理页码和实际摘录。
3. 本次勾选引用资料，再确认外部模型目标与发送内容。改变选文、片段或配置后需重新确认。

只有与当前题目同学科的片段可以提供给 Advisor；主进程重新核对实际存储的学科，阻止跨科引用。数学公式、上下标和符号可能乱码，必须核对 PDF 原页，不能把关键词命中当作公式验证。

请求只携带用户选中的片段标识；主进程从本地知识库解析真实文本，限制片段数量和长度。其他页、整本 PDF、题库私有解析和评分依据不会因此发送。原有“包括参考依据”是独立授权，与知识库无关。

模型只能引用此次提供的片段标识，显示的书名和页码由应用生成；未知引用会被拒绝。点击引文返回阅读器相应物理页。引用验证只保证片段存在和页码正确，**不能证明模型结论真实、引用充分或教材本身正确**。证据不足时允许明确回答不足。

用户主动导入的 PDF 原页可能自行包含例题答案或解析，本版不会识别或遮盖它们；角色隔离针对应用题库的私有参考存储，不是教材内容审查。

教材文本属于不可信资料，不能改变系统指令、请求其他文件或执行动作。提示仍留在 Advisor；不自动改写答案，也不进入独立阅卷上下文。

## 技术边界

上限为每份 50 MiB、1500 页、500 万提取字符，每页最多 10 万字符；每片段最多 1200 字符，每次最多 3 条证据。知识库最多 100 份 PDF，检索结果和阅读画布也有上限。解析线程 60 秒、阅读加载/绘页 30 秒后终止并提示重试。256 MiB 的线程限制仅约束 V8 堆，不等于整个进程的内存上限或操作系统沙箱。导入文件保留原始字节；知识库属于用户本机普通数据存储，不是加密保险箱。拥有本机文件权限的人仍可读取它。语义提示注入无法仅靠提示词保证完全消除，本版同时通过固定数据结构、最小载荷和无工具执行限制其影响。

PDF.js 使用官方 npm 包，解析/渲染文档参见 [PDF.js API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html) 与 [官方示例](https://mozilla.github.io/pdf.js/examples/)。源码测试只使用自编合成 PDF，不含真实教材或模型密钥。

## 私有教材资料包

通用程序及公开源码不包含教材。用户可把自己的 pack.json、PDF 或二进制分片放在同一文件夹，在知识库点“导入教材资料包”并选择 pack.json。程序逐份校验 SHA-256，分片在本机还原为字节一致的完整 PDF 后导入；不会改变物理页码、水印或版权标记。

先校验全包，再逐本原子保存。取消或某书解析失败时，已经保存的书保留，剩余项目明确显示；重试会去重，不覆盖旧资料。重复文件不擅自改变原有学科/版本，可单独编辑。缺件、哈希不符或不安全路径不会导入新文档。详见 [资料包格式](private-knowledge-pack.md)。
