# 动态钉板与圆、切线题库

## 入口与已有功能

数学工作台标题下新增“动态钉板 · 圆与切线 · 几何约束”折叠区。原来的函数、吸附、投影、二维坐标和三维几何工作台保留在下方。新钉板不依赖网络、iframe、外部几何服务或新增运行时包；使用本地 TypeScript 数学内核和 SVG。

题库放在 `examples/circle-tangent-bank.json`。在题库导入入口导入一次，按“圆与切线30题”标签筛选。30 题的题干、答案和分步解析没有修改；它们不会自动写入现有个人题库或学习记录。主观题本地关键词评分仍只是自查，不能判断完整推导正确性。

## 操作

支持自由点、线段、无限直线、射线、橡皮筋多边形、圆心加圆上一点、定半径圆、三点圆和逆时针圆弧。多边形依次点击顶点后点击首点或按 Enter 闭合；拖动自由顶点可以改变形状。圆弧第三点仅决定结束方向，不强制第三点落在圆弧上。

中点、平行线、垂线、垂足、轴对称点、直线/圆交点和切线采用保存引用的动态构造。拖动自由点后，依赖图形自动重算，不是保存一张失去约束的截图。线上/圆上点可拖动且始终投影回它所属的图形。线段上的约束点保存相对参数，端点改变后相对位置保持；交点分支使用固定的数值分支，不保证交点经过相切位置后保持拓扑身份。

退化、相离、平行、共线或圆内点等使构造暂不可用时，对象定义保留，图形隐藏并显示警告。恢复有效位置后自动出现。相切只有一个交点；重合直线或重合圆没有唯一交点，不伪造结果。

工具栏提供方格、等距三角、同心圆和无网格。步长为 0.01—100；滚轮缩放，Shift+滚轮调整步长，平移工具/空格拖动/中键拖动平移。新钉板坐标范围为 ±10000，原画布范围不变。密集网格会在显示时抽稀，但吸附仍使用用户选择的步长。I 切换标签显示。

对象面板支持名称、颜色、填充、显示/隐藏、自由点锁定、精确坐标和固定圆半径编辑。复制/平移/旋转/缩放/镜像创建独立副本，不改变原对象。镜像先关于过变换中心的竖直轴进行，再缩放、旋转和平移；副本是当前几何的快照，不带对原对象的隐含约束。

两点测距离，三点测角（第二点为角顶点）。线段报告长度；圆报告圆心、半径、标准式、面积和周长；多边形报告面积与周长，自交或重叠边不报告普通面积；圆弧报告圆心角与弧长。这些是浮点近似，不是 CAS 或正式数学证明。

每次拖动结束形成一次可撤销操作。支持撤销/重做、Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+Y、Delete 和 Escape。删除父元素会联动删除依赖对象，并在联动时确认；清空钉板有独立确认且可撤销。

可导入/导出完整钉板 JSON，导出 SVG。“复制旧画布点线”只创建独立副本，原图不动。JSON 导入须通过完整字段、类型、数量、引用、保留 ID 和无循环检查；不接受脚本或额外字段。导入过程中切换题目或作答变化时取消覆盖。

## 数据与兼容

仅新增可选字段 `MathWorkbenchState.geoboard?: GeoboardState` 和对应的原生 `mathWorkbenchSchema` 分支。不修改学习记录的版本，不为旧记录补字段。空钉板只在用户实际编辑时保存。原画布的撤销和重置保留当前钉板，新钉板的撤销不覆盖原图。

图形上限是 200 个点与 300 个对象，多边形最多 80 个顶点，名字最多 80 个 UTF-16 单元；JSON 导入文件最多 1 MiB。保存由现有应用 `onChange → draft → schema` 流程负责，没有独立 localStorage 或用户目录写入代码。切换外部文档会清空临时撤销栈。

## 验证与范围

仓库测试包含几何数值内核、原生 Zod 与完整草稿 Schema、JSON Schema 导出、真实 StudyService 在临时目录中的保存与重开、提交快照不变、题库原生导入和隔离，以及完整 MathWorkbench React 组件中的浏览器交互回归。Electron 测试仅使用临时 EXAMCRAFT_USER_DATA，不访问真实学习记录。

验证命令：`npm run check`、`npm run test:browser`、`npm run test:e2e`。以相应提交的 GitHub Actions 结果为准；测试存在不等于测试已通过。

这不是完整 GeoGebra 替代品：未新增 CAS、隐式曲线、解析式自动求交或一般非线性约束求解器；函数与三维功能仍用现有工作台。
