# 模拟教学地形工具

教学 Agent 与本地实验面板复用 `terrain_calculate`，不是让模型手绘等高线或声称自己已计算。工具是纯本地、确定性的数值程序，不联网、不读取文件或学习记录，也不执行用户/模型传入的公式、HTML、SVG 或代码。

## 数据模型与范围

- `terrain`：`version: 1`；`preset` 为 `peak`（山峰）、`depression`（洼地）、`ridge`（山脊）、`saddle`（鞍部）或 `plane`（均匀斜坡）。
- `widthM/heightM`：各 100–20000 m，长宽比 1:4–4:1。
- `baseElevationM`：−500–8000 m；`reliefM`：20–2000 m；`contourIntervalM`：5–500 m；起伏/等高距 ≤ 60。
- `gridCells`：16–64 的偶数；每边 `gridCells+1` 个节点。
- 可选 `probes`：最多 8 个有唯一 ID 的 `{id,xM,yM}`；可选 `profile`：`from/to` 和 2–65 个等距样点。所有点必须落在图幅内，剖面端点至少相距 0.01 m。

这些坐标是局部教学平面米数，不是经纬度；高程是合成值，不是实测 DEM。预设没有随机项，相同规格得到相同 ID、地形、线形和结果。ID 是确定性标识，不是防篡改签名。

## 数值方法

先用固定预设函数采样，再把每个网格沿西南—东北对角线分成两个三角形。权威教学表面是该分片线性三角网。查高程、等高线和剖面都使用同一个表面，避免显示与答案分别插值而不一致。

等高线用 marching triangles 提取，处理恰好等高的顶点和边，共享边去重，在二度顶点拼接折线。鞍点等临界顶点可以有多个合法分支，不伪造平滑桥接；等高平台的内部没有唯一等高线。最多 30000 个线段。图形相对于预设连续函数是网格近似，不能宣称是真实地形。

坡度百分数为 `100 × (终点高程−起点高程) / 水平直线距离`，倾角另以度数返回。两者不能混用，端点平均坡度也不能代表沿途各点坡度。剖面极值只是样点极值，可能遗漏样点间的极值。SVG 中有米制比例尺，不使用随窗口缩放变化的屏幕厘米比例。

## Agent 接口

工具返回紧凑 JSON：规格、单位、网格分辨率、采样全图高程范围、等高线层级、探测结果及可选剖面。它不把密集网格或完整线形塞给模型。应用渲染器自行用同一引擎绘制线形。

```json
{
  "terrain": {
    "version": 1,
    "preset": "peak",
    "widthM": 2000,
    "heightM": 2000,
    "baseElevationM": 100,
    "reliefM": 400,
    "contourIntervalM": 50,
    "gridCells": 32
  },
  "probes": [{ "id": "A", "xM": 250, "yM": 1000 }],
  "profile": {
    "from": { "xM": 250, "yM": 1000 },
    "to": { "xM": 1000, "yM": 1000 },
    "samples": 17
  }
}
```

该例返回 A=275 m、B=500 m、水平距离 750 m、有符号高差 225 m、端点平均坡度 30%。这是本地程序实际计算的结果。

外部 stdio MCP 仅在启动指定 `--reference-access full` 且未限定其他学科时注册 `terrain_calculate`。默认 student 服务器不暴露该教学能力，工具参数不能升级启动权限。计算器本身不读取题库参考答案；此权限限制避免把辅助解题计算能力无意分配给需要严格分离的角色。原点、线、多边形题图协议继续可用。

## 出题与解析

“AI 生成地理题”可选“模拟等高线 / 高差与坡度”。模型选择有界预设和剖面方向，实际数值题干、给定条件、参考解析和 rubric 由程序生成；拒绝模型传入的高程断言、题干/解析覆盖字段和可执行内容。出题参数使用 8 的倍数尺寸、整数基准高程/等高距、16 的倍数起伏、16/32/64 网格，确保公开给定的两位小数可复算。

预览和作答接口只返回公开题面与地形规格，不返回计算答案包、剖面、解析或 rubric。加入题库仍须明确接受，提交前不会从预览泄漏私有参考。正式阅卷可以取得计算证据；Advisor 只有在本次允许参考依据时取得该证据，默认只取得公开规格与题面。提交历史保留公开规格快照，提交后解析区可以重新绘制剖面。此隔离是应用接口边界，不是本机防作弊机制。

本地评分仍是粗略的文字关键词自查，不验证完整数值推导；模型审阅也不等于官方成绩。程序可复算数值，不能替代教学者对适用性和教学目标的判断。

## 本地实验面板

地理工作台中的折叠“教学地形实验”可换预设、换等高距、输入 A/B 剖面坐标、查询点高程。实验在本地运行，不替换作答、不修改真实地图坐标或普通地理图元；参数仅在当前面板会话保留。
