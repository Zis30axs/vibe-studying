# ExamCraft 0.2.0：整合与验证

本版本将数学工具、文科嵌套模块和学习热力图整合到同一份源代码中，基于六科版本 `6b6d5e0`。不再需要依次应用先前的独立补丁。

## 功能与兼容性

- 数学函数绘图、计算器、参数调节和交互几何，以及提交时的数学工具快照。
- 政治、历史、语文、地理的可拖放嵌套模块、点选/键盘替代操作、移除撤销、空白结构模板。
- 文科模块预览与最终正文独立；覆盖已有正文前显式确认；修改模块不静默覆盖手写内容。
- 最近 26 周的提交热力图；从持久化历史计算，重提交累计，草稿和失败请求不累计；本地日历分组，处理午夜、夏令时、闰年、无效及未来时间。
- 保留原 version-1 草稿、题库、历史和地理绘图；新增可选 math 与 argument 字段并执行完整边界校验。
- 当前正文与结构化工具数据仅在逐次同意后发送 DeepSeek；本地关键词自查不代表语义阅卷或官方成绩。

## 本地检查

- TypeScript、152 项 Vitest 测试及生产构建通过。
- 覆盖数学解析/计算边界、绘图保存、旧数据、嵌套草稿、最终正文独立性、不可变历史、时区/日期、真实 stdio MCP 往返和模拟 DeepSeek。
- Playwright 测试发现：20 个桌面 E2E 用例，包含数学、文科拖拽嵌套、热力图、六科练习、地理、云端模拟、开发模式与重启。

本地执行环境在 Electron 创建窗口前被 `process_singleton_posix.cc: socket() failed: Operation not permitted` 阻断。因此本地没有完成 GUI 验收，也没有绕过系统限制。

## 发布门禁

Windows CI 执行全部 Electron E2E。发布工作流还从官方 Electron Windows 运行时组装 ZIP，并启动**解压后的可执行文件**做烟雾测试。仅在规定检查成功后发布；具体成功记录、标签和附件以 GitHub Actions / Release 页面为准。

便携包不是仅含编译结果的源码压缩包：它包括 Electron 运行时、应用资源、许可证材料与启动说明。发布同时附对应源码与 SHA-256 校验。没有配置代码签名时，发布说明会明确标注未签名；Windows 可能显示系统安全提示。

真实 DeepSeek 服务未使用凭据验收。内置题均为原创教学演示，非历年真题。升级前备份本地用户数据；旧程序不保证可读取包含新字段的记录。
