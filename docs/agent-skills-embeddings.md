# Agent 学习技能与可选 Embedding

本次开发基于 `main@4e9ca1213d3f24780f68c00595bca55c122efddd`（v0.5.1）。2026-10-15 核对远端：0 个开放 PR，五个分支；其余为早期 MVP、几何钉板或已发布界面的历史分支，没有未合并的 Skill/Embedding 实现。本功能先在独立开发分支实现，随后按用户授权进入 v0.6.0 发布流程；v0.5.1 的标签与正式下载资源保留。

## 使用学习技能

打开 Agent 工作台，选择学科与“学习技能”卡片，填写普通中文任务，核对本次启用的工具。选择卡片会填写任务、必要时切换工作模式并勾选依赖工具；不会勾选答卷、参考答案、教材或发送同意。开始任务仍需配置聊天主模型并明确确认接收方和发送范围。Skill 步骤在本机执行，工具结果按本次 Agent 授权回传主模型。

| 技能             | 当前实际执行内容                                                                | 必要条件与边界                                                                                         |
| ---------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 解析几何分步引导 | 平面中点到直线的向量投影、垂足、距离及数值自检，分 1–4 步返回                   | 数学；每次只返回所请求的一步；支持竖直线和直线外延，拒绝重合端点                                       |
| 错题原因自查     | 对冻结答卷做本地选项/关键词规则评阅，列出可观察现象、待核对原因和重做建议       | 明确审阅模式，选中答卷与参考访问，启用评阅工具；不读取历史答卷；不是语义理解、正式评分或确定的心理诊断 |
| 针对性变式练习   | 按垂足、向量角、空间长度或体积生成基础/变化参数练习，图与参考解由同一计算器生成 | 数学创作模式；目前四种题型；用户确认预览后才入库，重复题仍由原保存机制拒绝                             |
| 知识点主动复习   | 从内置公式生成回忆问题、条件检查、例题和 0/1/3/7 天的复习建议                   | 当前覆盖数学、地理；建议不会创建提醒或改写学习记录，无命中如实返回                                     |
| 教材证据检索     | 返回授权教材、物理 PDF 页码内的片段、引用编号和来源                             | 六科均可，先选择同学科文档与页码；与其他教材工具共用本轮三段不同摘录、每段最多 1200 字的额度           |

运行界面的“本次实际执行的技能”由宿主工具成功回执生成；模型自行提及技能名称不会生成回执。关键词检查、数值计算和来源引用均有各自限制，需要对照题目和原页判断。

## 独立 Embedding 设置

在“配置模型 / 协议”中找到“Embedding 设置与检索”。配置 API 地址、模型 ID 和独立 Key。可与聊天使用不同服务商；地址填写 API 前缀，例如 `https://provider.example/v1`，也兼容以 `/embeddings` 结尾的完整接口。仅允许 HTTPS，或明确的 localhost、127.0.0.1、[::1] 本机 HTTP。网络连接使用系统 DNS、正常 TLS 校验；不会继承聊天模型的专用代理配置。

新 Key 默认仅在本次应用会话内存中使用。只有明确勾选系统加密保存才持久化；安全存储不可用时不保存明文。Key 不回填表单，不进入学习记录、向量索引、浏览器存储、模型日志或导出。更换 API 地址会清除原服务商凭据，需要重新填写；改变模型、地址或配置会使旧预览和查询缓存失效。

保存设置不发网络请求。连接诊断需要单独确认，只发送界面逐字展示的固定测试句，返回成功、维度或经过清理的错误提示；不会发送教材、作答或当前查询，不自动重试。

## 建立索引和语义检索

1. 先在教材库导入自有 PDF，选择学科、教材与不超过 100 个连续物理页。
2. 运行“本地检索（关键词回退）”，从结果勾选 1–3 个片段，点击“预览所选片段索引请求”。准备预览只做本地读取。
3. 核对完整文本、页码、内容 hash、实际接收接口和模型，再勾选“我同意发送本次预览内容”并确认发送。每个预览五分钟有效且只能使用一次；配置或原文变化时拒绝发送。
4. 输入新的语义查询，点击“预览语义检索请求”；这次只发送查询文本，匹配范围内已经建立的本地向量。查询没有关键词命中、没有勾选片段时也可预览。没有索引的内容不能被向量检索发现。
5. 同一应用会话内，Agent 的教材检索可复用**完全相同查询、学科、文档、页码范围与模型**的已授权查询向量；其他查询自动使用本地关键词，Agent 工具不能触发 Embedding 外发。

未配置或关闭服务、尚未批准查询、网络/响应失败、源文变化、缓存损坏或维度不兼容时，使用本地关键词；原教材本身损坏时仍会报错，不能凭旧缓存返回来源。关键词检索与原有学习功能不需要 Embedding API。语义相似度只是排序线索，不能证明教材支持某项结论。

本地派生索引按学科、文档 SHA-256、接口/模型指纹隔离，每条带片段内容 SHA-256、物理页、维度与向量；不复制教材正文或答卷。每个文档/模型最多保留 128 条，超出时淘汰较早条目。索引使用原子写入，损坏的派生缓存可重建；检索时通过原教材读取入口重新校验来源和文本。查询向量只留在内存，不持久化查询文字；清除范围索引会移除该页码范围的各服务商向量。新配置、取消或关闭窗口会中止请求并使待确认预览失效。没有自动整书扫描、后台批量上传、远端向量数据库或自动作答上传。

服务商可能保留已发送请求；界面确认会展示接收方与精确文本。聊天模型接收教材的授权不能替代 Embedding 的逐次确认，旧索引也不能扩大 Agent 当前获准的学科、文档和页码。

## 扩展与接口

`src/shared/agent-skills.ts` 保存版本化目录、严格参数 schema、学科/模式和依赖工具；`src/domain/agent-skills.ts` 保存本地处理器。添加技能时同时增加受审阅的 ID、schema、目录和处理器。宿主不下载或执行用户、模型、PDF 或网页提供的代码。处理器只接收 registry 提供的受限工具调用能力，不接触凭据、文件或学习历史。

`list_skills` 只返回本轮权限可执行的目录；`run_skill` 先校验参数和依赖，再复用现有 registry 的授权、错误处理、教材累计额度与提案流程。外层调用和每个内部调用均计入六次总预算；现有三次主模型、两次委派、120 秒和会话预算保持不变。工具定义总上限由 20 调整为 22，不改变请求或写入权限。

`EmbeddingService` 管理独立配置、OS 密钥封装、精确预览能力票据、请求和关键词回退。`KnowledgeVectorIndex` 管理可删除的本地派生向量。IPC 复用现有主窗口来源校验；所有输入都做运行时校验。接口使用 `POST /embeddings`，请求 `model`、字符串数组 `input` 和 `encoding_format: float`，校验返回序号、数量、非零有限向量及一致维度；拒绝重定向、超时、超限响应和凭据反射。协议依据 [OpenAI 官方 Embeddings API](https://developers.openai.com/api/reference/resources/embeddings/methods/create)，兼容服务商仍需独立验证。

新增单元/模拟接口测试覆盖技能数学步骤、权限过滤、错误清理、确认前不写题、共享教材与工具预算、凭据生命周期、外发票据过期/重放/源文变化、响应边界、取消和索引回退。集成测试使用真正生成的合成 PDF，经现有解析器、源文件校验、本地索引、确认后的模拟向量接口和 Agent 教材技能取回证据，并检查其他页与用户目录隔离。桌面测试使用独立临时用户目录和假凭据，外部请求被拦截。

本机桌面测试默认设置 `EXAMCRAFT_E2E_SILENT=1`，仅在开发构建与独立测试用户目录中启用：主窗口隐藏、不占任务栏，不弹出原生错误框或未模拟的文件选择框。GitHub hosted Windows 使用独立虚拟桌面，完整原生拖选/拖拽回归按正常可见窗口运行；专门的 Agent 能力用例仍强制隐藏并断言不显示、不抢焦点。正常启动和发行包不启用此模式。浏览器与桌面报告使用不同子目录，避免并发清理彼此的 trace。测试接口替换必须等真实主窗口初始化完成，防止与正式 IPC 注册竞争。

尚未验证真实供应商凭据、服务商模型质量与配额、macOS/Linux 系统密钥链、发行包安装升级。没有读取或上传用户真实教材、作答或 API Key。错因语义诊断、跨学科完整复习课程、任意解析几何题型和整书向量化不在当前实现范围。
