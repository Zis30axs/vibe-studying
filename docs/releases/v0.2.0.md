# ExamCraft v0.2.0

Windows x64 首个可下载运行的便携版：解压完整的 `ExamCraft-0.2.0-win-x64.zip`，打开其中的 `ExamCraft.exe`。无需安装 Node.js，不要只单独移动 EXE；旁边的 `resources`、DLL 和其他文件也要保留。

## 本次更新

- 学习热力图：最近 26 周按本机日期显示已保存的提交，点选某天即可回看记录；草稿与失败提交不计数。
- 数学交互工作台：拖动与精确编辑点、线段、距离/角度测量、函数参数、撤销、草稿及历史快照。
- 文科模块工作台：语文、政治、历史、地理的观点、材料、分析、结论自由组装，支持因果/对比/分点嵌套、拖动排序、键盘点选、撤销和正文预览。
- 保留六科原创演示题、本地保存、规则自查，以及逐次同意后才能使用的可选 DeepSeek 评阅。

## 下载与校验

- `ExamCraft-0.2.0-win-x64.zip`：实际可运行的 Windows x64 应用，包含 Electron 运行时。
- `ExamCraft-0.2.0-source.zip`：与发布提交对应的项目源代码和构建说明，开发者使用。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA-256 校验值。Windows PowerShell 可运行 `Get-FileHash .\ExamCraft-0.2.0-win-x64.zip -Algorithm SHA256`，与文件中的值比较。

## 重要说明

- EXE 图标及 Windows 文件属性保留 Electron 运行时标识和版本；应用内部版本、打包元数据与发布版本均为 0.2.0。
- 此版本未签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。请只运行你确认可信的下载；校验值用于检查文件一致性，不能代替发布者身份验证。
- “便携版”表示免安装；学习数据仍保存在 `%APPDATA%\ExamCraft`，不是 EXE 旁边。升级前先退出旧版并备份整个数据目录。新增答案字段不保证可由旧版读取。
- 没有自动更新器、Windows 安装程序、macOS 或 Linux 安装包；其他平台仍可从源代码运行。
- 本地反馈只是学习自查，不能代替正式阅卷。DeepSeek 请求可能计费，需要用户自己安全配置凭据并逐次同意发送；发布测试使用模拟请求，未验证真实模型评分质量。
