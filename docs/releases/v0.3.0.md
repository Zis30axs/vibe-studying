# ExamCraft v0.3.0

Windows x64 便携版：解压完整的 `ExamCraft-0.3.0-win-x64.zip`，打开其中的 `ExamCraft.exe`。无需安装 Node.js；请保留 EXE 旁边的 `resources`、DLL 和其他运行时文件。

## 本次更新

- 答案优先布局、可折叠的学习概览与可调高度工作台。文科模块可自由放置、平移、缩放，并保留逻辑结构、正文顺序与持久化布局。
- Ask Advisor 选文提示，以及克制的模块检查、逐条差异预览和手动接受。版本树支持检查点、恢复及分支；顾问提示不会自动写入最终答案。
- 自定义 Anthropic Messages、Gemini generateContent、OpenAI Responses 和 Chat Completions 四类文本协议。模型密钥仅在当前应用进程会话中使用，重启后需重新输入。
- 作答题面、顾问参考授权与提交后阅卷的载荷隔离；阅卷使用提交时的独立快照，不混入顾问对话、版本树或画布布局。这不是本机文件层面的防作弊机制。
- 地理原创示意题生成、结构校验、预览和接受后保存。模型输出的事实、可解性及评分质量仍需人工核验。
- 六科本地 PDF 知识库、分页阅读、中文词法检索、章节与物理页码范围，以及按次授权的 Advisor 摘录引用。
- 私用教材资料包导入：先解压资料包，在应用选择“导入教材资料包”并打开其中的 `pack.json`。文件按书校验和合并、按内容摘要去重，取消后可重试。
- 可选 GitHub 公开头像与用户名展示，不使用 OAuth，也不取得私有仓库权限。

## 教材与隐私

公开应用包与源码不附带真实教材、用户文档或私有索引。教材资料包需另外取得并仅在有权使用的范围内导入。请保留解压后的包目录结构，不要将教材放入公共仓库或公开附件。

本地知识库不会自动上传教材。顾问使用摘录前，界面会列明摘录、书名、物理页码和模型目标，并要求本次发送授权。阅卷不会自动接收知识库教材数据。

## 下载与校验

- `ExamCraft-0.3.0-win-x64.zip`：实际可运行的 Windows x64 应用，包含 Electron 运行时。
- `ExamCraft-0.3.0-source.zip`：对应发布提交的项目源代码与构建说明，供开发者使用，不能代替运行包。
- `SHA256SUMS.txt`：上述两个 ZIP 的 SHA-256 校验值。PowerShell 可运行 `Get-FileHash .\ExamCraft-0.3.0-win-x64.zip -Algorithm SHA256`，与文件中的值比较。

## 升级与已知限制

- 升级前退出旧版，备份 `%APPDATA%\ExamCraft`。便携版免安装，但学习资料仍保存在该独立数据目录；不要直接覆盖、移动或删除旧学习数据。新增数据字段不保证可由旧版读取。
- 此版本未签名；Windows 可能显示未知发布者或 SmartScreen 提示。请只运行可信来源的文件。校验值检查文件一致性，不代替发布者身份验证。EXE 图标与 Windows 文件属性保留 Electron 运行时标识，应用内部与打包元数据版本为 0.3.0。
- 没有自动更新器、安装程序、macOS 或 Linux 安装包。其他平台可从源码运行。
- PDF 文本检索依赖文件中的文本层；纯扫描页可能无法检索，不提供自动 OCR。课程标签和物理页码范围不等同于已核对的教材目录。
- 模型调用可能计费，需自行安全配置并逐次授权；模型测试使用模拟响应，不保证真实服务可用性、事实或评分质量。本地反馈也不能代替正式阅卷。
- 保留 GPL-3.0-only 许可证；运行包包含项目、Electron 及已打包依赖的许可证声明。
