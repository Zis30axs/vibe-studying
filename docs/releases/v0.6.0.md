# ExamCraft v0.6.0 — 学习 Skill 与独立 Embedding

- Agent 工作台增加五种可执行学习技能：解析几何分步引导、错题原因自查、针对性变式练习、知识点主动复习和教材证据检索。内置技能有版本、严格参数校验、权限过滤和真实执行回执，可在现有工具机制上扩展。
- 几何引导支持点到直线的垂足与距离；变式覆盖四种参数题型。错因分析是明确标注不确定性的本地规则自查；主动复习卡当前覆盖数学、地理。新题和答卷修改仍需用户确认，不自动提交或改写学习记录。
- Embedding 可单独配置 API 地址、模型 ID 和 Key，兼容标准 OpenAI-compatible Embeddings 接口，可与聊天使用不同服务商。密钥默认仅用于本次会话，可明确选择系统加密保存；更换服务地址会清除旧凭据。
- 建立教材索引或嵌入查询前，展示接收方、完整文本与内容指纹，逐次确认后才发送。连接诊断只发送固定测试句；Agent 的普通教材检索不会自动调用 Embedding API。
- 本地向量索引按学科、文档、内容 hash 和服务模型隔离；重新验证教材来源，索引过期、损坏、接口失败或未授权时回退关键词。每次索引 1–3 个片段，每文档/模型最多保留 128 段，不自动上传整本教材或作答历史。
- 保留教材物理页码授权、每轮三段摘录额度、工具预算、预览确认和学习记录隔离。修复测试启动时替换 IPC 的竞态，桌面开发测试改为隐藏窗口，浏览器与桌面报告分开保存。

使用方法、扩展入口与边界见 [Agent 技能与 Embedding](../agent-skills-embeddings.md)。沿用 v0.5.1 的主界面、快速查找、题目导航、专注模式与动效设置。

Windows 下载为免安装 ZIP：完整解压后打开目录中的 `ExamCraft.exe`，无需 Node.js；请保留旁边的 `resources` 和运行文件。升级前关闭旧程序并备份 `%APPDATA%/ExamCraft`。程序未签名，附带源码与 SHA-256 校验文件。

发布工作流通过双平台类型检查、单元/接口模拟/合成 PDF 集成测试、浏览器回归、Windows 桌面回归、打包及真实 ZIP 解压冒烟后才创建正式 Release。测试未使用真实教材或服务商凭据；真实供应商兼容性、模型效果及 macOS/Linux 密钥链仍需各自环境验证。
