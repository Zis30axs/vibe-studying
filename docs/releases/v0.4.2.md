# ExamCraft v0.4.2

## 几何出题模板与配套工具

- 新增四类内置原创几何出题模板：空间向量、三角形高线与平行线、斜平行六面体、正方形底面棱锥。模板使用受限参数，由本地程序生成题干、给定图和参考解析，经确认后入库。
- 数学工作台新增过点垂线与垂足构造，以及可旋转的 x/y/z 三轴几何画板，支持点、线段、三角面和立方体示例。三维投影只作示意；几何计算工具使用原始坐标，支持向量、垂足、线面角与体积。
- 几何状态随草稿、提交记录和重启保留；题目给定图与学生作图区分离，参考结论不预置在学生场景。
- 数学出题模式会自动向 Agent 提供四类模板策略；用户用自然语言说明练习目标即可。Agent 与 MCP 新增受限几何生成和计算工具，保留启动同意、入库确认、参考信息隔离和已有调用预算。

模板参数、数学条件及工具边界说明随源码提供。

## 下载与使用

Windows 用户下载 `ExamCraft-0.4.2-win-x64.zip`，完整解压后打开 `ExamCraft.exe`。源码 ZIP 用于查看和自行构建，不是 Windows 运行包。升级前备份现有学习数据。

发布须通过完整单元、浏览器、Windows 桌面测试，以及实际解压 ZIP 的几何保存重启、公式收藏和 PDF 冒烟验收。具体记录见对应 GitHub Actions。模型测试使用合成数据和模拟响应，没有真实 API 凭据验收。

程序未代码签名。内置题与生成模板为教学练习，评分不是官方考试评分。三维示意图与数值采样不能代替数学证明；地图来源与许可说明沿用包内文档。
