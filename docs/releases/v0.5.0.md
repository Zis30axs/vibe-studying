# ExamCraft v0.5.0 — 动态几何与圆、切线训练

## 数学工作台

新增本地动态钉板：自由点、线段、无限直线、射线、多边形、两种基本作圆、三点圆、圆弧；中点、垂足、平行线、垂线、反射点、交点、圆切线、线上及圆上约束点。拖动自由点后依赖构造联动；退化构造保留定义并显示提示，恢复条件后重新出现。

支持方格/等距三角/同心圆钉板、吸附、平移缩放、精确坐标、对象颜色与填充、隐藏/锁定、变换副本、距离/角度/面积/周长、撤销重做和 JSON/SVG 导出。数学工作台中的“动态钉板 · 圆与切线 · 几何约束”打开新工具，原函数及三维工具保持可用。所有数值测量仅作近似参考，不是 CAS 或数学证明。

## 30 题递进题库

`examples/circle-tangent-bank.json` 包含圆标准式、位置约束、切线、弦长、点到线距离的 30 道练习。各题含答案、分步解析与易错点；按原生 version 1 格式手动导入。题目不会自动写入个人题库，解析沿用提交后的显示边界。主观题关键词评分不能作为正式数学判分。

## 数据兼容与验证

新增可选 `math.geoboard` 字段，不修改旧记录版本，不为旧草稿自动补字段，不删除旧题库或提交。旧画布撤销不会覆盖新钉板，新钉板撤销不会覆盖旧画布。新增内核、Zod、保存/重启/快照、题库导入、React 浏览器和 Electron 回归测试。使用新字段后的记录不保证旧版本应用可读，请保留升级前备份。
