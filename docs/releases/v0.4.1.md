# ExamCraft v0.4.1

## 公式速查

- 新增独立的离线公式速查页，内置 29 条原创中文教学条目：数学 18 条、地理 11 条。
- 支持关键词、别名和公式编号搜索，学科/章节筛选，以及保存在本机的收藏。切换页面保留检索位置与未提交答卷，重启后仍可查看收藏。
- 每条公式列明适用条件、符号与单位、常见误区、原创算例及来源链接；表达式使用安全纯文本展示，不执行输入内容。
- 速查内容是通用教学参考，不替代题目条件，也不声称覆盖所有课程公式。

## Agent 与 MCP

- 原生 Agent 和受限 MCP 角色可检索、按编号读取同一内置公式库，返回可复核的版本、适用条件与来源。
- 检索仍受已选学科、白名单、条数与原有调用预算约束；未知编号不编造结果。
- 内置公式来源与用户私有教材引用分开标识；收藏和学习数据不会附带在公式检索结果中。

## 打包与使用

- 提供 Windows x64 可运行 ZIP；完整解压后运行 ExamCraft.exe，无需安装 Node.js。
- 程序未签名。请仅运行可信来源的下载，并在升级前备份本地学习数据。
- 程序与源码不包含教材、API 密钥或个人资料。模型协议测试使用合成服务，不代表所有真实供应商均已验收。
- 固定文本资源换行，避免 Windows 源码归档改变已记录的数据文件哈希。
