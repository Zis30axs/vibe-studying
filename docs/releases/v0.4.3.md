# ExamCraft v0.4.3

## Agent 题目上下文

- 从练习页进入 Agent 时保留眼前的题目、学科筛选、搜索结果和对应草稿，修复数学页面的可见题目被旧选择替换的问题。
- 空搜索范围保持为空；切换不同练习工作台时明确重置筛选。公式往返与历史恢复保留正确的题目身份。
- 答卷快照仍须主动勾选；不可附带时说明未选题、学科不一致或预览处理中等原因。

## 获取模型与连接诊断

- 获取模型列表仍使用服务接口下的 `/models`，无需预先填写模型名称。
- 失败时提供固定的 DNS、TLS、连接、安全检查、HTTP 或读取响应阶段，以及允许显示的错误码或 HTTP 状态。
- 不支持模型列表的接口会给出单独提示。修复无响应体状态在传输层被误判的问题。
- 本地 Debug 增加模型列表和连接测试的脱敏元数据；不记录密钥、服务端错误原文、响应正文或私有地址。关闭 Debug 或退出程序后清除会话记录。

这些改动帮助定位失败原因，不代表任何自定义服务已恢复连接。发布测试使用合成错误及模拟服务，没有使用真实服务凭据。公网 HTTPS、证书验证、禁止重定向和逐次请求同意等保护保持不变。

## 使用

Windows 用户下载 `ExamCraft-0.4.3-win-x64.zip`，完整解压后打开 `ExamCraft.exe`。升级前备份学习数据。程序未代码签名。

完整单元、浏览器、Windows 桌面和实际 ZIP 验收记录见对应 GitHub Actions；源码和 SHA-256 校验文件随版本提供。
