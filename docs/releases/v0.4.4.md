# ExamCraft v0.4.4

修复模型连接无法明确采用 Clash Verge 等本机代理的问题。旧版在直连 DNS 检查时会拦截 Fake-IP，导致模型列表在发送前报 `ENDPOINT_NOT_PUBLIC`。

- 模型设置新增「直连 / 使用系统代理 / 指定本机代理」。旧配置保持直连；使用 Clash 时可明确选择系统代理，或填写已有 HTTP / 混合代理端口。
- 模型获取、API 连接测试、实际生成、审阅和 Agent 请求共用所选网络路径；诊断可以测试当前编辑值，实际任务使用已保存值。
- 本机代理使用 HTTP CONNECT 与原域名 TLS 校验；仅在这条路径允许 `198.18.0.0/15` Fake-IP，其余私网限制保留。API 凭据不发送到 CONNECT 请求，也不跟随重定向或在代理失败后自动直连。
- 修改网络配置会取消旧请求，保留同一接收方的密钥。代理错误使用固定诊断信息，不显示原始网络错误、密钥或响应正文。
- 已废弃的旧桌面 DeepSeek 提交入口会提示使用已迁移的模型配置，防止绕过当前网络设置。

仅支持本机 `127.0.0.1` / `[::1]` 的无认证 HTTP 代理，不支持 SOCKS、远程代理或代理认证。系统明确选择 DIRECT 时仍执行直连公网检查。应用不修改 Clash、系统代理、防火墙或证书设置。配置步骤与代理信任边界见 [模型连接与 Clash Verge](../model-network.md)。

回归覆盖本地真实 CONNECT/TLS 隧道、分块响应、取消、超时、DNS/私网边界、证书拒绝、重定向与凭据隔离，并检查配置持久化和桌面界面。所有凭据和服务均为测试夹具；未调用用户真实 API，也不声称已验证用户的 Clash 配置、服务额度或模型质量。

Windows 下载 `ExamCraft-0.4.4-win-x64.zip` 后完整解压运行 `ExamCraft.exe`。升级前退出旧版并备份学习数据，使用 `SHA256SUMS.txt` 核对压缩包。便携包仍未签名，没有自动更新器；配套源码为 `ExamCraft-0.4.4-source.zip`。
