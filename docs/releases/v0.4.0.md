# ExamCraft v0.4.0

## 模型配置与诊断

- 保存多个具名模型配置，快速为正式阅卷/出题与选文提示/模块检查分别分配模型。主模型负责有界工具编排与正式任务，子模型处理受限提示/模块检查及可选网络工具续接，不进行无限递归。
- API Key 默认隐藏；可选择仅本次会话使用，或通过系统安全存储加密保存。安全存储不可用时拒绝持久化，绝不降级明文。留空保留原密钥，换接收方需重新输入。
- 支持 Anthropic Messages、Gemini、OpenAI Responses、Chat Completions 兼容接口的模型列表获取和搜索，保留手动输入。
- 连接测试只发送极短固定探测，不发送学习内容，可能产生少量 API 费用。模型列表成功与实际模型调用成功分别展示。
- 可开启仅本次会话的 Debug 诊断：记录阶段、耗时、HTTP 状态、协议/模型、格式校验路径及错误类别。默认关闭，不记录 API Key、请求或响应正文、答卷或教材。关闭即清空，可复制脱敏诊断。

## 审查体验

- AI 审查、模块检查、提示和出题显示进行状态、已用时间与取消入口，不显示虚构完成百分比。
- 首次确认时可选择记住对特定接收方与数据类别的同意。换题或同地址换模型不反复询问；新接收方或新增数据类别仍需确认。设置可撤回；教材摘录仍需用户明确选中。
- 修复取消文字选区后 Ask Advisor 悬浮按钮残留、旧选区事件复活等问题；样式与应用统一，支持减少动画设置。

## 数学输入与画布

- 支持可选 `y=`、常见隐式乘法（如 `2x`、`2(x+1)`、`(x+1)(x-1)`、`3sin(x)`）。
- 应用前显示规范化表达式，失败保留原有绘图；仍使用受限解析器，不执行任意代码。

- 画布右键创建吸附点，鼠标旁显示当前坐标与步长；滚轮按 1 → 0.5 → 0.25 → 0.24…0.01 调整精度，可设置自定义步长并保存在草稿。
- 标记点与悬停点可显示到坐标轴的投影虚线和距离；默认浅灰，可改色、通过可见开关或 I 快捷键切换，并保留设置。

## 文科模块组装

- 拖近小模块或已有大模块时预览吸附，组内紧凑排列；双击选中组内小模块后可拖出拆分，支持撤销与历史快照。
- 明确分组独立于逻辑父子关系、正文顺序和画布位置。模型检查按组分析可能不同的小题或思路，部分选择保留范围标记；正式提交仍以用户确认的最终正文为评分依据。

## 布局、外观与记录

- 四区工作空间支持折叠、持久化栏宽、拖拽/键盘分隔线与窄窗抽屉；学习概览仅在练习记录直接展开。
- 浅色/深色/跟随系统、本地壁纸与透明度/模糊/位置/适配设置。安全栅格副本只在本机，原图不修改，不发送给模型。
- 六科学科独立提交时间线，冻结题面/答卷/评分反馈；旧数据缺失明确标注。
- AI 求助从真实答卷检查点分支；收到提示标记参考 AI，实际采纳修改才合并。取消、失败、历史未知分别显示，恢复创建新分支，来源状态不影响评分。

## 地图与教学地形

- 新地理草稿默认世界轮廓，可切离线地形/明确来源的 Natural Earth 省州参考，支持缩放平移与标注对齐。
- 资料不是 Google 美区或中国审定政治图；未伪造中国红边界及南海政治线，来源与版本随程序分发。
- 教学等高线引擎确定计算模拟曲面、探点、剖面、距离与坡度；AI 选择有界规格后由本地计算生成可复算题目/解析，非真实 DEM。

## 原生 Agent 工具

- 四协议支持真实 tool call → 白名单执行 → 结果回传 → 继续回答，统一 16 个题库/教材/数学/地理/评阅/出题/建议与可选网络工具。
- 显示工具过程、错误、耗时和取消；限制模型轮数、调用数、委派、总时限及会话预算，不自动付费重试。
- 权限固定在用户选择的题目/学科、答卷、教材页码和接收方范围；参考/教材派生结果回传主模型也需要对应授权。
- 写操作先预览确认，旧建议与并发新编辑隔离；创建模式可本地审核新生成答案，工具回传与普通题目读取保持学生安全投影。

- 新增可选 Tavily 公开资料检索与安全直接 Fetch。主、子模型使用同一已确认公开范围及共享联网额度；来源/取得时间/年份提及明确显示，生成题目保留未核验或改编来源标记。供应商 Key 独立使用系统安全存储或会话存储。不会把任意模型查询直接发送到网络。

## 审阅知识点索引

- 从已保存审阅反馈建立待关联知识点，手动确认真实 PDF 片段后保存本地关联；支持改标签、解除关联和原页查看。
- 文档/片段指纹与提交身份复核，失效来源明确标记；Agent 可按索引或片段编号精确取回，仍受本次同学科文档页码、发送同意及累计摘录上限约束。
- 不声称自动完成整本书语义索引，不把未使用教材的评阅伪装成已有教材依据。

## 边界

- 所有新增模型验证均使用合成输入与模拟服务，不代表任意第三方模型、真实凭据或评分质量已验收。
- 私有教材不随源码或程序分发；原有本地练习、六科知识库、PDF 与资料包导入保持不变。
- 本机加密保护受系统账户/密钥环安全性影响，不提供跨设备密钥同步。
