# ExamCraft v0.4.5

改进模型连接兼容性，支持服务商返回的中文和其他 Unicode 模型名称，并简化 Windows 本地开发启动。

- 模型配置、连接诊断、普通请求与 Agent 原生工具请求统一支持包含中文、空格及斜杠的模型 ID；仍拒绝空值、控制字符及超过长度限制的名称。Gemini 请求按单一路径段编码模型 ID。
- 模型 Base URL 支持 HTTP/HTTPS、本机与私网服务、自定义端口；直连使用默认 DNS，兼容 Clash TUN，不再预先分类公网、私网或 Fake-IP。HTTPS 保留证书及主机名校验，仍拒绝重定向；本机代理失败不自动切换路线。
- HTTP 连接不加密传输，请只连接可信服务；向远程模型发送数据前仍需按当前配置确认授权。
- 模型设置与授权提示简化；新增 Windows `run.ps1` 开发启动入口，并更新连接与协议说明。
- 桌面无效模型回归改用真正非法的控制字符；补充 Anthropic、Gemini、OpenAI Responses 和 OpenAI Chat 四种 Agent 协议的 Unicode 模型名回归。

协议回归使用合成凭据和模拟响应，不调用用户真实 API，不读取用户学习数据，也不代表已验证特定服务商的模型质量或用户代理设置。独立旧版 DeepSeek 环境变量适配器不属于本次模型配置路径兼容性修复范围。

Windows 下载 `ExamCraft-0.4.5-win-x64.zip` 后完整解压运行 `ExamCraft.exe`。升级前退出旧版并备份学习数据，使用 `SHA256SUMS.txt` 核对压缩包。便携包仍未签名，没有自动更新器；配套源码为 `ExamCraft-0.4.5-source.zip`。
