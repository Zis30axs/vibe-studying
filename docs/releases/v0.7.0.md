# ExamCraft v0.7.0

新增独立“数学挑战”模式，可从左侧导航或快速查找进入，练习带有整卷答题卡和倒计时的综合试卷。

- 提供 8 单选＋3 多选＋3 填空＋5/6 解答题两种版式，均为 150 分、120 分钟。
- 首套原创综合卷覆盖空间向量、直线与圆，并衔接二次函数、三角与不等式；不是历年真题。
- 支持答题卡跳题、多选作答、标记、草稿、自动保存、重开继续和到时交卷。
- 交卷后自动核对选择题，填空与解答题按参考步骤自行核分；待核分项不会被冒充为已评分。
- 独立保留每次挑战历史与试卷快照，不修改普通题库和单题练习记录。

使用方法与评分规则见 [数学挑战](../math-challenge.md)。
